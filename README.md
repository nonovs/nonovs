## 🧭 Proyecto destacado

### [CaminoVivo](https://github.com/xabiernovoa/CaminoVivo)
**Proyecto ganador del HackUDC 2026 (reto de Grafana Labs).**

CaminoVivo agrega datos públicos gallegos en una plataforma unificada para el Camino:
- 🌦️ Meteorología
- 🛏️ Albergues
- 🚰 Fuentes de agua
- 🗺️ Rutas GPS
- 🎭 Eventos culturales

Con visualización interactiva en Grafana para facilitar la planificación de peregrinos y usuarios.
